TeleBrief

A bilingual Telegram intelligence feed with a two-stage AI filtering pipeline.

The problem

Keeping up with many Telegram channels creates a second problem: deciding what deserves attention. Repeated stories, low-value posts and changing formats make a raw feed difficult to use. TeleBrief turns that stream into source-linked, structured digests.

Under the hood

The collection layer uses Telethon and MTProto. Messages are batched for a first-pass shortlist, then merged into a final report. The code separates digest generation from the command interface, which handles user preferences, report tasks and cancellation. Model fallbacks and deduplication make the pipeline less dependent on a single response.
