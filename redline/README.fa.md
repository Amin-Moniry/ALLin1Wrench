# ALLin1Wrench / REDLINE v2

پیشنهاد بازطراحی پرتفوی امین منیری. رنگ اصلی دقیقاً همان `#DC143C` مخزن فعلی است؛ قرمز روشن‌تر برای متن روی حالت تیره استفاده می‌شود. Dark/Light و فارسی/انگلیسی حفظ شده‌اند.

## اجرا
`index.html` را باز کنید یا `python3 -m http.server 8080` اجرا کنید. کد زمان اجرا وابستگی npm ندارد. تمام محتوای تحریریه در data.js است. محتوای اصلی از README، صفحات پرتفوی و مخزن‌های عمومی صاحب حساب گرفته شده است؛ هیچ سابقهٔ استخدام یا نتیجهٔ تجاری ساختگی اضافه نشده است.

## تغییرات
- Hero جدید با تایپوگرافی بزرگ و تصویر اختصاصی روبان کریمسون.
- چیدمان تحریریه‌ای پروژه‌ها، فیلتر دسته، گالری کیبورد/drag و جابه‌جایی به پروژهٔ بعدی.
- Command palette با Ctrl/Cmd+K، جست‌وجوی محلی بخش‌ها و پروژه‌ها، Arrow/Enter/Escape.
- Preloader منابع، motion محدود، parallax، marquee، magnetic و tilt؛ reduced-motion همهٔ حرکت‌های اصلی را غیرفعال می‌کند.
- اطلاعات واقعی ALLin1Wrench، TeleBrief و BotAM و مهارت‌های وب، AI، n8n و شبکه.
- صفحات legacy موجود در مخزن حذف نمی‌شوند؛ landing قدیمی در legacy-landing.html حفظ می‌شود.

## افزودن بخش در ۳ خط
۱. به sections در data.js یک آبجکت با id یکتا و type:'content' اضافه کنید.
۲. nav، title و body را با {en:'...',fa:'...'} بنویسید؛ items اختیاری است.
۳. ذخیره و reload؛ بخش و منو خودکار ساخته می‌شوند.

## فرم‌ها و تاریخ
سرویس ارسال ایمیل هنوز متصل نیست. ایمیل عمومی صاحب حساب لینک mailto دارد؛ فرم خبرنامه و تماس موفقیت ساختگی نمی‌دهند. برای اتصال، newsletterEndpoint و contactEndpoint را به POST JSON هم‌مبدأ وصل کنید؛ هیچ کلید API در مرورگر قرار ندهید. تاریخ ۲۰۲۷ در کارت‌های آینده فقط نمونه است؛ می‌توانید launchAt را null کنید. CSRF، rate-limit، اعتبارسنجی سرور و double opt-in مسئولیت backend هستند.

## فایل‌های نسخهٔ گیت‌هاب
برای ارسال امن با ابزار متنی MCP، فونت‌های محلی در CSS و تصاویر در سه فایل visuals-N.js به‌صورت data URI بسته‌بندی شده‌اند. نسخهٔ ZIP تصاویر AVIF/WebP و فونت‌های WOFF جداگانه دارد. هر دو نسخه بدون build اجرا می‌شوند. افزایش اندازهٔ encoding هزینه دارد؛ قبل از انتشار، برای cache بهتر می‌توانید به فایل‌های باینری جداگانه برگردید.

## کیفیت
نتیجهٔ تست واقعی در QA-results.json آمده است. Lighthouse بالای ۹۰، ۶۰fps روی سخت‌افزار واقعی و انطباق کامل WCAG در این محیط تأیید عددی نشده‌اند. Safari/Firefox/گوشی واقعی، SEO دو‌زبانه و اتصال ایمیل را پیش از انتشار آزمایش کنید.

## نتیجهٔ آخرین تست
۱۱۳ بررسی از ۱۱۳ بررسی Chromium پاس شدند: شش عرض ۳۶۰ تا ۲۵۶۰، فارسی/انگلیسی، reduced-motion، گالری کیبوردی، Escape و فوکوس، فیلترها، Command palette، فرم بدون اتصال/خطا/موفقیت شبیه‌سازی‌شده، تاریخ نامعتبر/گذشته، خطای تصویر و no-JS. اجرای تست بدون وابستگی: `BASE_URL=http://localhost:8081 node redline/tests/qa-native.mjs` در نسخهٔ گیت‌هاب؛ ابتدا سرور محلی را روی همان پورت اجرا کنید.
