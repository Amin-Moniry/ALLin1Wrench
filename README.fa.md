## متفاوت می‌سازم؛ با مدرک، نه شعار

ALLin1Wrench پروژه‌های رابط وب، هوش مصنوعی، اتوماسیون و سه‌بعدی تعاملی را در یک مسیر منسجم معرفی می‌کند. هدف فقط نمایش کاور نیست: هر پروژه، مسئله، معماری، تصمیم مهندسی، توانمندی، محدودیت و ردپای منبع خودش را دارد.

هویت **REDLINE** از قرمز `#DC143C`، زمینهٔ نزدیک به مشکی، تایپوگرافی درشت، خطوط ظریف، شماره‌گذاری و نشانه‌های ساده ساخته شده است. حالت روشن همین زبان را روی زمینه‌ای گرم و کاغذی ادامه می‌دهد.

### داخل هر مطالعهٔ موردی

۱. **مسئله:** چه چیزی باید ساده‌تر یا قابل‌استفاده‌تر شود؟  
۲. **زیر پوست:** ماژول‌ها، مرزبندی‌ها و پیاده‌سازی.  
۳. **تصمیم مهندسی:** یک انتخاب مهم و دلیل آن.  
۴. **توانمندی‌ها:** قابلیت‌های مشخص، نه نتیجهٔ تجاری ساختگی.  
۵. **جریان سیستم:** معماری ساده‌شده بر اساس سورس.  
۶. **محدودیت و وابستگی:** نیازهای تنظیم و چیزهایی که تضمین نمی‌شوند.  
۷. **ردپای منبع:** README و فایل‌های اصلی پیاده‌سازی.

### تصاویر با برچسب درست

- TeleBrief: اثر گرافیکی اصلی مخزن؛ نه اسکرین‌شات برنامه.
- Executive Bot: اسکرین‌شات واقعی گردش‌کار n8n، با حذف قاب مرورگر.
- DetectSafeVisionX: نمونه‌های واقعی خروجی تشخیص از مخزن.
- BotAM: تصویر توضیحی معماری/زبان؛ صریحاً نه اسکرین‌شات اپلیکیشن.
- 3D Visualizer: تصاویر واقعی نمایشگر، از جمله مدل بارگذاری‌شده.

مشتری، جایزه، درصد دقت، درآمد، سرعت پاسخ یا پایداری سرویس اختراع نشده است. [مستند منابع پروژه‌ها](redline/docs/PROJECT-SOURCES.md)

## تعاملات و حرکت

- **Ctrl + K / ⌘ + K:** جست‌وجوی سریع پروژه و فناوری.
- **کیبورد:** حرکت میان نتایج و تب‌ها؛ خروج از پنجره با Esc.
- **فیلتر پروژه‌ها:** تغییر دسته و بازگشت به هر پنج پروژه.
- **معماری:** انتخاب پروژه و دیدن مسیر ورودی تا نتیجه.
- **گالری:** بزرگ‌نمایی تصویر در dialog بومی مرورگر.
- **موبایل:** منوی مستقل، چیدمان باریک و متن راست‌به‌چپ.
- **حرکت:** ورود عنوان، reveal کوتاه، پارالاکس محدود، بازخورد دکمه و ورود مرحله‌ای گره‌ها.

لودر مسدودکننده و نشانگر سفارشی سراسری وجود ندارد. کنترل حرکت و `prefers-reduced-motion` تجربه را آرام‌تر می‌کنند؛ خواندن محتوا به انیمیشن وابسته نیست.

### آزمایشگاه؛ واقعی و محلی

**Signal Field** موج را در Canvas رسم می‌کند؛ فرکانس و حرکت فاز قابل‌کنترل‌اند.  
**Language Mirror** متن کاربر را در جهت خودکار، چپ‌به‌راست یا راست‌به‌چپ نمایش می‌دهد؛ **مترجم نیست**.

هیچ‌کدام درخواست مدل، مصرف توکن یا API بیرونی ندارند.

## دوزبانه از پایه

فارسی فقط ترجمهٔ منو نیست؛ جهت خواندن، چیدمان، کپی رابط و تایپوگرافی تغییر می‌کنند. نام پروژه‌ها و برچسب فناوری در ترکیب فارسی/انگلیسی خوانا نگه داشته می‌شوند.

انتخاب زبان و تم در صورت دسترسی به فضای ذخیره‌سازی مرورگر، محلی حفظ می‌شود. بدون انتخاب صریح، تم می‌تواند از ترجیح سیستم شروع شود.

## زیر پوست سایت

![نمودار معماری استاتیک پرتفوی REDLINE](docs/readme/architecture.svg)

```text
HTML → محتوای دوزبانه → رندر بخش‌ها → تعاملات و حرکت → رابط قابل‌استفاده
                                     ├── تصاویر محلی با بارگذاری نزدیک viewport
                                     └── ترجیحات محلی زبان، تم و حرکت
```

- هسته و ابزارهای مشترک: `redline/scripts/core.js`
- رندر صفحه و مطالعه‌های موردی: `redline/scripts/sections.js`
- تعاملات، جست‌وجو و تماس: `redline/scripts/interactions.js`
- حرکت: `redline/scripts/motion.js`
- آغاز برنامه: `redline/scripts/app.js`
- محتوای دوزبانه: `redline/content/site.js` و `projects.js`
- سه ماژول CSS: `base.css`، `components.css` و `responsive-motion.css`

خود سایت بک‌اند، دیتابیس، ورود حساب یا سرویس مدل ندارد. معماری پروژه‌ها نمایش توضیحی است، نه اجرای زندهٔ سرویس‌های آن‌ها.

### بسته‌بندی تصاویر و فونت‌ها

به‌دلیل متنی‌بودن اتصال انتشار این نسخه، تصاویر سایت در JSONهای محلی با data URI و فونت‌ها داخل CSS قرار دارند. تصاویر با `IntersectionObserver` نزدیک محدودهٔ دید و با کش Promise بارگذاری می‌شوند؛ همهٔ تصاویر گالری در شروع دریافت نمی‌شوند. تصویر اصلی eager است.

آرشیو سورس تحویلی، فایل‌های اصلی WebP / WOFF را هم دارد. تصاویر README جدا در `docs/readme/` نگه داشته شده‌اند و به بارگذاری اولیهٔ سایت اضافه نمی‌شوند.

## اجرای محلی

نیازها: Git، Python 3 و مرورگر جدید. برای اجرای سایت نصب پکیج لازم نیست.

```bash
git clone https://github.com/Amin-Moniry/ALLin1Wrench.git
cd ALLin1Wrench
python3 -m http.server 8080
```

آدرس: **http://localhost:8080/**  
فارسی تیره: **http://localhost:8080/?lang=fa&theme=dark**

سایت را روی HTTP اجرا کنید. بازکردن مستقیم `index.html` با `file://` برای دریافت تصویرهای محلی مناسب نیست.

## کنترل کیفیت با مرز روشن

**۶۰۶ بررسی Chromium بدون شکست در اجراهای ثبت‌شدهٔ انتشار.** همان مجموعه برای سورس اصلی و بستهٔ انتشار اجرا شده؛ این عدد ۱۲۱۲ تست مستقل نیست.

- عرض‌های ۳۶۰، ۳۹۰، ۷۶۸، ۱۰۲۴، ۱۴۴۰ و ۲۵۶۰ پیکسل.
- فارسی/انگلیسی و روشن/تیره.
- پنج مسیر مطالعهٔ پروژه در دو زبان و عرض‌های ۳۹۰ و ۱۴۴۰.
- سرریز، شناسهٔ تکراری، جهت، فیلتر، تب کیبوردی، جست‌وجو، منوی موبایل، FAQ، متن امن، پیش‌نویس ایمیل، ترجیحات و reduced-motion.
- گالری، لینک‌های داخلی، anchorها و حالت بدون جاوااسکریپت.
- ۱۲ بررسی اضافی چیدمان منتشرشده، مسیر خانه→پروژه→خانه و decode تصاویر.
- هفت جفت رنگ اصلی با کنتراست حداقل ۴٫۵:۱ برای متن عادی AA.

دامنهٔ زنده نیز پس از انتشار برای مسیر پروژه‌ها، تصاویر، جست‌وجو و موبایل بررسی شد.

**تأیید نشده:** پوشش Safari/Firefox، نرخ فریم دستگاه واقعی، سازگاری کامل با فناوری کمکی، گواهی کامل WCAG، دقت مدل، پایداری ربات‌های تلگرام یا ارسال ایمیل سمت سرور. نتیجهٔ بدون شکست در محدودهٔ تست، تضمین نبود خطا در همهٔ شرایط نیست.

## پژوهش طراحی

۱۰۰ تصویر متفاوت از آرشیو Awwwards به‌صورت بصری بررسی شد. ۱۰۳ صفحهٔ متفاوت جزئیات/پیش‌نمایش هم بارگذاری و خوانده شد؛ این دو مجموعه بخشی از هم‌پوشانی دارند.

بازدیدهای منتخب از Dennis Snellenberg، Lusion، Bruno Simon و Locomotive نیز انجام شد؛ تصویر لودر به‌جای بررسی کامل تجربه حساب نشده است. README هر ده مخزن عمومی سازنده خوانده شد و برای پروژه‌های منتخب بررسی عمیق‌تر سورس انجام گرفت.

این آمار **به معنای تست کامل تعامل ۱۰۰ سایت زنده نیست**. الهام‌گرفتن از مراجع به معنی دریافت جایزه، همکاری یا تأیید آن‌ها نیست.

## انتشار و حفاظت از نسخهٔ قبل

نسخهٔ جاری مستقیم روی `master` منتشر شده و شاخهٔ جدیدی ساخته نشده است. `CNAME`، دامنه و پوشه‌های قدیمی حذف نشده‌اند.

فایل ورودی قبلی در [`redline/docs/V2-ROOT-BACKUP.txt`](redline/docs/V2-ROOT-BACKUP.txt) برای بازگشت آگاهانه نگه‌داری می‌شود. این به‌روزرسانی README، مستندات و تصاویر مستندات را تغییر می‌دهد، نه رفتار اجرای سایت.

برای انتقال به میزبان دیگر، کل ساختار را منتقل کنید؛ کپی‌کردن فقط `index.html` کافی نیست.

## پرسش‌های کاربردی

**فرم تماس ایمیل می‌فرستد؟** خیر. پیش‌نویس `mailto:` را در برنامهٔ ایمیل کاربر آماده می‌کند. سایت پیام را ارسال یا ذخیره نمی‌کند.

**ابزارهای پروژه‌ها داخل سایت اجرا می‌شوند؟** خیر. سورس و در موارد موجود لینک خارجی تلگرام ارائه شده است. وابستگی و مجوز هر ابزار متعلق به همان پروژه است.

**برای گزارش مشکل چه بنویسم؟** در [Issues](https://github.com/Amin-Moniry/ALLin1Wrench/issues)، آدرس صفحه، مرورگر، عرض، زبان/تم، مراحل بازتولید و نتیجهٔ مورد انتظار را بفرستید. تصویر کمک‌کننده است؛ رمز، توکن یا اطلاعات خصوصی نفرستید.
